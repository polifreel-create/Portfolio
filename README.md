# Портфолио Полины Ефремовой

Статичный сайт на HTML, CSS и JS, без сборки и зависимостей.

## Структура

```
v2.html                 — главная (вариант 2): слева карточка о себе, справа лента кейсов
giga-case.html          — страница кейса «Гигасправка»
index.html              — главная (вариант 1): тёмный первый экран, кейсы в сетке
css/v2.css              — стили главной (вариант 2): токены, шкалы текста и отступов
css/case.css            — стили страниц кейсов (подключаются после v2.css)
css/style.css           — стили главной (вариант 1)
assets/fonts/           — шрифты (Onest — текст, Bebas Neue — имя), подключены локально
js/main.js              — анимации: свет при скролле, сцена в обложке, видео
assets/img/hero/        — аватар и логотипы компаний
assets/img/giga/        — слои обложки Гигасправки и картинки кейса
assets/video/           — видео кейсов (MP4, H.264, без звука)
```

## Как посмотреть локально

Открыть `index.html` в браузере. Для корректной работы видео лучше запустить простой сервер:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000

## Публикация

- **Vercel / Netlify:** New Project → импорт репозитория → без настроек сборки (Framework: Other, Output: корень).
- **GitHub Pages:** Settings → Pages → Branch: `main`, папка `/ (root)`.

## Как добавить кейс

Скопировать блок `<article class="case">` в `index.html`, заменить тексты и картинки.
Ассеты класть в `assets/img/<имя-кейса>/`.

## Что заменить перед запуском

- Ссылки Telegram, LinkedIn, CV и адрес почты (шапка и подвал)
- Аватар, логотипы и картинки кейса — сейчас вырезаны из скриншотов, нужны оригиналы

## Дизайн-система

- Сетка: 12 колонок, промежуток 24 px; поля 16 / 24 / 40 px (телефон / планшет / десктоп).
  Текст кейса — 4 колонки, визуалы — 8.
- Отступы: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128 px (переменные --s-1 … --s-10).
- Текст: подпись 12, мелкий 14, основной 16, название кейса 26–32, первый экран 24–40.
